# 下午茶筆記（PWA）

記錄想去、去過的下午茶店。資料存在手機本地（IndexedDB），可以離線使用。

## 功能
- 新增／編輯／刪除店家：店名、地區、地址或地圖連結、想去/去過、評分、造訪日期、價位、標籤、筆記、照片
- 篩選（全部／想去／去過）、搜尋、排序
- 一鍵開啟 Google 地圖
- 匯出／匯入 JSON 備份
- IG／來源連結欄位、Google 地圖連結欄位、📋 從剪貼簿新增、匯入捷徑收件匣
- 同一家店從 IG 和 Google 地圖各存一次，會自動合併（比對店名／連結）

## 從 IG / Google 地圖收藏：「加到下午茶」捷徑
一鍵安裝：https://www.icloud.com/shortcuts/92b988b274084014bbebccc5750cf06e （app 內「⋯ → ⚡ 安裝捷徑」也是這個連結）

自己從頭做的步驟：

1. 捷徑 app → 右上「＋」→ 名稱改成「存到下午茶」。
2. 點下方「ⓘ」→ 開啟「在分享表單中顯示」，接收類型只留「URL」和「文字」。
3. 加入動作（依序）：
   1. **要求輸入**：類型「文字」，提示「店名（可空白）」
   2. **要求輸入**：類型「文字」，提示「地區（可空白）」
   3. **文字**：內容輸入 `teatime|`［提供的輸入］`|`［提供的輸入（第 2 個）］`|`［捷徑輸入］
      （［…］是點「變數」插入的藍色泡泡）
   4. **拷貝到剪貼板**：輸入選上一步的「文字」
   5. **附加到檔案**：資料夾 `Shortcuts`、檔案路徑 `teatime-inbox.txt`，開啟「建立新行」
   6. （可選）**顯示通知**：「已存，打開下午茶筆記按 📋 貼上」
4. 用法：
   - **單筆**：IG 貼文 → 分享 →「存到下午茶」→ 打開 app 按右上「📋 貼上」→ 檢查後儲存。
   - **一次多筆**：平常只按捷徑收藏，之後在 app「⋯ → 匯入捷徑收件匣」選 iCloud 雲碟裡的 `Shortcuts/teatime-inbox.txt`，重複的連結會自動略過。

### 附上截圖當首圖（可選）
在捷徑的「文字」動作前加：**尋找相片**（篩選：是截圖、建立日期在最近 5 分鐘，排序最新，限制 1 張）→ **調整影像大小**（寬 800）→ **轉換影像**（JPEG）→ **Base64 編碼**（換行：無）。
「文字」改成 `teatime|店名|地區|捷徑輸入|img:`＋［Base64 編碼結果］。使用時先在 IG 截圖，再按分享 → 加到下午茶。

也可以不用捷徑：IG「分享 → 複製連結」後直接在 app 按「📋 貼上」。

## 部署到 GitHub Pages（免費）
1. 在 GitHub 建一個新 repo（例如 `tea-notes`），把這個資料夾所有檔案放到根目錄並 push。
2. Repo → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，儲存。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/tea-notes/`。

（也可以用 Cloudflare Pages / Vercel / Netlify，直接拖拉資料夾或連 GitHub。）

## 加到 iPhone 主畫面
1. 用 **Safari** 打開上面的網址。
2. 點下方「分享」→「加入主畫面」→「加入」。
3. 之後從桌面圖示打開，就是全螢幕 app。

## 本機測試
```bash
python3 -m http.server 8000
# 電腦瀏覽器打開 http://localhost:8000
```
（Service Worker 需要 HTTPS 或 localhost；手機要測離線功能請用部署後的網址。）

## 更新程式
改完檔案後，把 `sw.js` 裡的 `CACHE = 'tea-notes-v1'` 版本號加 1 再部署，手機關掉 app 重開一兩次就會換成新版。

## 注意
- 資料只存在那台裝置的那個瀏覽器（從主畫面開的 app 跟 Safari 分頁的資料是分開的）。
- iOS 可能清除很久沒開的網站資料，請定期用「⋯ → 匯出備份」存一份到「檔案」或雲端。
